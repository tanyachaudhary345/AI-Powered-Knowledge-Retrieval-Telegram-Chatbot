# AI-Powered PDF Knowledge Retrieval Chatbot

An AI chatbot built using n8n, OpenAI, Qdrant Vector Database, Google Embeddings, and Telegram.

## Features

- PDF document ingestion
- Vector search with Qdrant
- Retrieval-Augmented Generation (RAG)
- Telegram chatbot interface
- AI-powered question answering

## Tech Stack

- n8n
- OpenAI
- Qdrant
- Google Gemini Embeddings
- Telegram Bot API

## Workflow

PDF → Extract Text → Generate Embeddings → Store in Qdrant

User Question → AI Agent → Retrieve Relevant Chunks → Generate Answer
